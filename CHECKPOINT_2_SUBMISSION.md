# Week 3 — Data Pipeline + Baseline Model

## Deliverables included
- Image-folder ingestion and image integrity validation.
- RGB conversion, 224×224 resize, training-only augmentation and ImageNet normalization.
- Reproducible stratified 70/15/15 split and JSON split manifests.
- ResNet-18 baseline training script using AdamW and cross-entropy.
- Held-out evaluation script for accuracy, class-wise precision/recall/F1, macro ROC-AUC, confusion matrix and COVID-19 false-negative rate.
- Baseline report and explicit record of dataset availability.

## Dataset dependency / honest status
The supplied Checkpoint 1 ZIP contains healthcare symptom/test-case files but no chest X-ray images. The scripts are implemented, but a real model cannot be trained and benchmarked until the approved NORMAL, PNEUMONIA and COVID-19 image folders are supplied. No fabricated performance metrics are included.

## Run after placing the approved images in data/xray_raw/
```bash
pip install -r requirements.txt
python src/prepare_data.py
python src/train.py --epochs 10
python src/evaluate.py --checkpoint models/best_resnet18.pt
```
