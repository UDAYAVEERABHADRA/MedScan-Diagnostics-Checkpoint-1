# Chest X-ray dataset location

Place the approved image dataset here, keeping one folder per class:

- `NORMAL/`
- `PNEUMONIA/`
- `COVID-19/`

Supported image formats: JPG, JPEG, PNG, BMP, TIFF.

The Checkpoint 1 ZIP did not contain the 3,000 chest X-ray images. The healthcare symptom CSV and text test cases are not substitutes for X-ray images and must not be used to train this image classifier. Do not add identifiable patient data or upload restricted medical images to a public repository.
